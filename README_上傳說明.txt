HVAC 複合型風管紀錄 - 綠色風管圖示更新版

本次只更新手機桌面圖示、PWA 圖示檔名與離線快取版本；保留原程式所有計算及資料儲存邏輯。

GitHub 上傳：
1. 先在原網頁匯出案件 JSON 備份。
2. 解壓縮本 ZIP，將下列全部檔案上傳至 github.com/life1019hs-spec/hvac-duct-record 的 main 分支根目錄：
   index.html
   manifest.webmanifest
   sw.js
   duct-icon-192-v3.png
   duct-icon-512-v3.png
   duct-apple-touch-v3.png
3. Commit changes。確認 Settings > Pages 部署成功。
4. iPhone Safari 開啟 https://life1019hs-spec.github.io/hvac-duct-record/?icon=v3，分享 > 加入主畫面。
   iPhone 上原有捷徑通常不會自動更換圖示，請先備份案件，再移除舊捷徑重新加入。

請勿上傳 ZIP 檔本身作為網站首頁；需先解壓縮並上傳所有檔案。
